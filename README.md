# TRACKORA

**Know. Track. Protect.**

TRACKORA is a premium, privacy-first location intelligence concept built with Next.js, TypeScript, Tailwind CSS and the provided ORI mascot artwork. It focuses on consent-based device tracking, secure phone/email/OAuth login UX, resilient live dashboards and a friendly AI companion named ORI.

## Highlights

- Futuristic landing page with glassmorphism, aurora gradients and animated ORI artwork.
- Secure login hub concept with phone OTP, email/password, OAuth, passkeys, 2FA, trusted devices and lockout messaging.
- Permission-based live tracking modes for GPS pulse, route replay, safe zones, offline recovery, map layers and trip reports.
- Security-first product messaging for input validation, secure headers, CSRF/XSS/injection protection, suspicious login detection and privacy controls.
- ORI AI assistant patterns that troubleshoot permissions, summarize activity and request confirmation before sensitive changes.
- Pricing, FAQ and contact sections ready for a Vercel deployment workflow.

## Getting started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production checks

```bash
npm run typecheck
npm run build
```

> Note: real phone OTP, authentication, database storage, map providers, push notifications and AI provider integrations should be connected through environment variables before production launch.
